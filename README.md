# Wereduck · 5人局在线对战

一款鹅鸭杀风格的5人在线社交推理网页游戏。
5位玩家可通过手机或电脑浏览器进入同一房间实时开局对战。（调整规则可以支持更多玩家）

- 游戏创意基于鹅鸭杀、狼人杀两款经典手游；
- 游戏规则文档 `rules.txt` 由此github账号主人袁晨皓独立撰写；
- 项目代码全部由 OpenCode(GLM-5.2) 生成。

## 运行

```bash
# 安装依赖
pip install -r requirements.txt

# 启动
./run.sh
# 或手动：
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

启动后浏览器访问 `http://localhost:8000`。其他玩家通过内网穿透访问你的电脑。

## 玩法

1. **创建/加入房间**：首页点「创建房间」获得4位房间号，或输入房间号「加入房间」。
2. **落座**：选1~5号空座 + 输入昵称 → 入座。5人到齐后所有人点「准备」自动开局。
3. **夜间阶段**：系统按 rules.txt 顺序依次唤醒每位有夜间行动的角色。轮到你时界面弹出行动面板（击杀/钻管道/侦查/吞食等），其他时间显示「夜晚进行中」。
4. **白天轮麦**：1→5号顺序发言，每人限时。轮到你时可发言，点「结束发言」交棒。刺客/渡鸦/喜鹊可在此时猜身份。
5. **投票阶段**：所有存活玩家选投票对象。鹈鹕/猎鹰只能弃票，呆呆鸟/说客可投自己。
6. **游戏结束**：公示胜方阵营和全部角色。所有人点「准备」可开启下一局（重新随机角色，聊天清空）。

## 功能

- **角色搜索**：右下角 📖 按钮随时查看全部24个角色的描述和阵营。
- **标记功能**：点其他玩家座位可给其标记一个角色（仅自己可见，保存在浏览器 localStorage）。
- **断线重连**：浏览器会保存本房间重连身份；刷新或关闭标签页后，只要服务端房间仍存在，可从首页继续回到原座位。服务重启、房间被全员离线清理或等待超时后无法恢复。

## 角色配置

每局从全部24个角色中按 **3鹅阵营 + 1鸭阵营 + 1中立阵营** 随机抽取分配。

## 夜间行动顺序

```
跟踪者 → 鸽子 → 工程师 → 鸭阵营(钻管道) → 警长 → 正义使者 → 士兵 → 说客
→ 鸭阵营(击杀) → 鹈鹕/猎鹰 → 侦探 → 殡仪员 → 白天
```

严格按顺序依次唤醒。后面步骤的局面依赖前面步骤的选择（死亡、管道、相邻链重算等）。

## 胜利条件优先级

呆呆鸟 → 喜鹊 → 鸽子 → 秃鹫 → 生存主义者 → 鹈鹕/猎鹰/渡鸦 → 鸭阵营 → 鹅阵营

## 技术栈

- 后端：Python FastAPI + WebSocket，纯内存房间状态
- 前端：原生 HTML/CSS/JS，移动端响应式

## 超时配置

可通过环境变量调整各阶段超时（秒）：

```bash
WEREDUCK_NIGHT_TIMEOUT=25 WEREDUCK_SPEECH_TIMEOUT=60 WEREDUCK_VOTE_TIMEOUT=30 ./run.sh
```
